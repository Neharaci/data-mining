# Data Mining & Data Warehousing Lab Exam

This repository contains the work completed for Question 1 and Question 2 of the Data Mining & Data Warehousing Lab Exam.

## Evidence and Documentation

For both **Question 1** and **Question 2**, the repository includes:

- The **scripts/code** used to perform the required tasks and analysis.
- **Screenshots of the outputs** obtained during execution.
- **TXT files containing a summary of the outputs, results, measurements, and observations** for the respective question.

The evidence has been organized separately within the `question-1` and `question-2` folders for easy reference.
